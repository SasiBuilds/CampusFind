# 🎓 Campus Find – Smart Campus Navigation Web App

A modern and responsive **Campus Find web application** built using **HTML, CSS, and JavaScript**.  
This project helps users easily explore and navigate campus locations through a simple and interactive user interface.

---

## 🚀 Project Overview

**Campus Find** is a beginner-friendly frontend project designed to simulate a campus navigation system.  
It focuses on strengthening core web development skills such as UI design, layout structuring, and JavaScript-based interactivity.

This project helps users understand how digital maps and campus directories can be visually represented in a simple web application.
